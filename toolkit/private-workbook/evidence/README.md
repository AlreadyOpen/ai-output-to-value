# Private evidence folder

Store or reference only the evidence needed for the decision. This folder is an organisational working area, not a public case-study requirement.

Examples include:

- acceptance-test or evaluation results;
- representative input/output fixtures;
- contract or end-to-end test evidence;
- baseline and after measurements;
- incident, rollback or recovery evidence;
- runbooks, monitoring and support records;
- approvals or authority records where relevant;
- cost measurements relevant to the decision.

Prefer links or identifiers into the organisation's existing controlled systems when copying the raw evidence here would create unnecessary security, privacy, contractual, retention, or duplication risk.

Do **not** put passwords, API keys, credentials, secrets, unnecessary personal data, or material that the organisation is not authorised to retain in this folder.

The public AI Output to Value project does not need access to this material.
